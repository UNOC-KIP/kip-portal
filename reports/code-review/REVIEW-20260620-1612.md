## Changes applied this run

### 1. G-ADMIN-UI — Wire "Confirm" button in admin bank-transfers table

`TransferRow` in `mappers.ts` now carries `paymentId` and `paymentStatus`
(the mapper input grows `id` and `status`). The query in `queries.ts` passes
`p.id` and `p.status` to `toTransferRow`. The `bank-transfers-table.tsx` client
component is now wired:

- "Confirm" calls `POST ${API_BASE}/payments/:paymentId/confirm` with
  `credentials: "include"` (cookie auth in the browser).
- The button is disabled when `paymentStatus !== PROOF_UPLOADED` (proof not yet
  uploaded), and shows a loading label while in-flight.
- Per-row error messages appear below the action buttons on failure.
- On success, `router.refresh()` re-fetches the server component so the row
  disappears from the queue.
- "View" (proof download) and "Reject" are visually present but disabled; "View"
  awaits Phase 3 presigned-GET wiring; "Reject" awaits a `POST /payments/:id/reject`
  endpoint.
- `mappers.test.ts` updated to include `paymentId` / `paymentStatus` in the
  `toTransferRow` test case.

**Files changed:**
- `apps/web/src/lib/admin/mappers.ts`
- `apps/web/src/lib/admin/queries.ts`
- `apps/web/src/app/(admin)/console/bank-transfers/bank-transfers-table.tsx`

### 2. A5 — Deduplicate `STAFF_ROLES` in `applications/route.ts`

The local `STAFF_ROLES = new Set([...])` in the applications router was a copy
of the same set in `apps/web/src/lib/rbac.ts`. Replaced with a one-liner
`isStaff(role): boolean => role !== UserRole.INVESTOR` — all non-INVESTOR roles
are staff, so the set is equivalent and the redundant list is gone.

**File changed:** `apps/api/src/modules/applications/route.ts`

### 3. B-NULL — Null safety gap in `getApplicationDetail`

`investor-data.ts` line 245 accessed `a.investorOrg.legalName` without optional
chaining. The include is a LEFT JOIN so `investorOrg` can be null if the
associated org was removed (unlikely given FK constraints, but the type cast hid
the risk). Fixed with `a.investorOrg?.legalName ?? "—"`, matching the same
null-safe pattern used in `admin/queries.ts`. The `AppWithIncludes` local type
updated to reflect `investorOrg?: InvestorOrg`.

**File changed:** `apps/web/src/lib/investor-data.ts`
